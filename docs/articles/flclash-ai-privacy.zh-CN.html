第一次用 Clash：从安装、导入订阅到 AI 分流与 Skill

English · 返回项目首页 · 进阶排障

这篇教程假设你从来没用过 Clash，也没写过配置文件。你会先让一个普通网页正常打开，再学会让不同网站使用不同连接，最后用 Skill 请智能体协助检查和修改。前半程不需要终端，也不要求先买住宅 IP 或香港服务器。

Clash 是一类按规则处理网络连接的软件。你通常安装的是带操作界面的客户端，例如 FlClash、Clash Verge Rev；客户端里面还有负责实际转发的“内核”。本篇用 FlClash 示范点击步骤，共同概念也适用于其他 Clash 家族客户端。

下载入口指向官方发布页。本次资料核对日期为 2026-10-03，官方最新版本为 0.8.99；主要菜单也核对了公开源码。原案例唯一实机版本仍是 macOS FlClash 0.8.98，其他平台和新版本未实机验收。菜单布局可能不同，按按钮名称寻找；其他客户端先看兼容说明。

1. 下载和安装

1.1 先知道自己用什么设备

只选与你设备匹配的一行，不需要安装所有版本。

你的设备 怎么确认 选什么安装包
Apple 芯片 Mac 左上角苹果菜单 → 关于本机，看到 Apple M 系列芯片 名称含 macos-arm64.dmg
Intel Mac 关于本机显示 Intel 处理器 名称含 macos-amd64.dmg
常见 Intel/AMD Windows 电脑 设置 → 系统 → 系统信息/关于，系统类型为 x64 名称含 windows-amd64-setup.exe
Windows ARM 电脑 同一位置显示 ARM64 名称含 windows-arm64-setup.exe
Android 手机 通常使用 ARM；按官方页面及设备架构确认 对应的 APK，现代 ARM 手机通常为 arm64-v8a
Linux 先确认发行版和处理器架构 Debian/Ubuntu 用对应 DEB；其他按官方 DEB/RPM/AppImage 说明选

FlClash 官方没有本篇可用的 iPhone/iPad 安装包。不要把 Android APK 下载到 iPhone 后尝试打开。

1.2 打开官方页面并找安装包

  1. 在浏览器打开 FlClash 官方下载页。
  2. 找到页面下面的 Assets，意思是“这个版本的下载文件”。如果列表收起来了，点开它。
  3. 按上一张表选文件。不要选 Source code：那是开发代码，不是普通用户的安装包。
  4. 等下载完成，在浏览器下载列表或电脑的“下载”文件夹找到它。

1.3 安装并打开

Mac：双击 DMG → 把 FlClash 拖进“应用程序/Applications” → 打开“应用程序”中的 FlClash。安装包窗口和已安装的软件是两处位置，日常从“应用程序”打开。若系统阻止打开，先确认文件来自上述官方页面，再按 macOS 提示处理；不照抄关闭系统安全检查的命令。

Windows：双击 setup.exe → 确认安装的是 FlClash → 按安装器完成安装 → 从开始菜单打开。系统可能要求管理员授权。初次使用优先选安装器，ZIP 解压版不保证相关系统组件已安装。

Android：打开下载的 APK → 按手机提示允许这个下载来源安装 → 安装后打开 FlClash。以后第一次开始连接时，还会出现 Android 的 VPN 连接授权，那是另一步。

Linux：用发行版的软件安装器安装对应 DEB/RPM；AppImage 则在文件属性中允许执行后运行。若报缺少组件，按官方说明和AppImage 操作说明处理，不把 Ubuntu 的命令复制到所有发行版。

完成标志：你能打开 FlClash，看到“仪表盘、代理、配置”等页面入口。现在还没有节点、也还不能通过代理上网，是正常的。

2. 节点、机场、订阅分别是什么

先认识后面真的要点到的词，不需要记协议参数。

词 它具体指什么 你会在哪里遇到
节点 一条代理连接的配置，包含服务地址、端口、连接方式和认证信息 “代理”页中可选择的条目，例如供应商标注的香港、日本节点
机场 这里指提供一组代理服务的服务商 服务商网站提供套餐、使用说明、节点和订阅链接
订阅链接 客户端用来下载、更新配置的私人链接 从服务商后台复制，粘贴到 FlClash 的 URL 导入窗口
配置文件 软件实际使用的一整份设置，通常是 YAML 文件 “配置”页的一张卡片；里面可以同时有节点、组和规则
代理组 把节点或其他组放在一起，供手动或自动选择 “代理”页的分组页签，例如“自动选择”
规则/分流 决定某个网站的连接应该走 DIRECT、某个节点或某个组 “请求/连接”记录，以及 YAML 的 rules 部分
DIRECT 由设备所在网络直接连接目标，不经过所选代理节点 大陆网站或局域网服务可以使用这个目标
静态住宅代理 服务商提供的固定出口代理；固定性和住宅属性需分别验证 有些人用它给特定海外 AI 服务提供稳定出口，并非安装 Clash 的必备条件

FlClash 本身不提供机场套餐或可用节点。仅安装软件，不会自动获得代理服务。你需要一个自己有权使用的订阅，或服务商提供的完整配置文件。本教程不替你选购服务商。

订阅链接常带访问凭证。把它留在客户端或自己的私人文件中，不贴进 AI 对话、公开评论或截图。节点里的用户名、密码也一样。

3. 把订阅导入 FlClash

3.1 从服务商后台复制正确的链接

  1. 打开你使用的服务商后台，找到“订阅”“客户端订阅”或“使用教程”。
  2. 选择标注 Clash、Clash Meta 或 Mihomo 且适合你客户端的格式。某些站点的一键导入也能用，但这里先学手工 URL 导入。
  3. 点击该格式的“复制链接”。不要复制后台网页的地址，也不要选择另一个客户端的专用格式。

如果你拿到的是完整 .yaml 文件，直接走下一节的“文件导入”，不需要自己把文件变成订阅链接。

3.2 在客户端粘贴

  1. 打开 FlClash 的 配置 页面。
  2. 点 +，也就是 添加配置；没有配置时，也可点击空页面的添加配置按钮。
  3. 选择 URL。
  4. 在导入窗口中粘贴刚才的私人订阅链接。0.8.99 还可输入名称，填一个你能辨认的名字，例如“我的日常订阅”；0.8.98 的窗口标题为“从URL导入”。
  5. 点 提交，等它下载完成。
  6. 成功后会出现一张配置卡片。点击这张卡片，把它选为当前配置。已有多张卡片时，不要以为新导入的必定已经被选中。
  7. 打开 代理 页面，确认出现节点或分组。

这些入口见官方导入实现。

文件导入：配置 → + → 文件 → 选择服务商给你的完整 YAML → 导入后点击卡片选中。不要选择本仓带占位符的教学片段，它不是完整可用配置。

完成标志：配置页有被选中的卡片，代理页有实际成员。看到“节点为空”或下载报错，就先解决导入，不继续叠加 DNS、TUN 等设置。

遇到什么 先做什么
下载失败或超时 确认服务商后台能打开、复制的是完整链接、套餐仍有效；必要时使用服务商提供的完整文件
导入后提示格式错误 回后台重新选 Clash/Mihomo 格式；可能下载到了登录页或别的客户端格式
新配置有卡片，代理列表还是旧的 回配置页点击新卡片，核实当前选择
不知道是哪张卡片 先在配置编辑页查看并给它取一个能辨认的名称，不凭名称中的国家判断真实出口

4. 第一次连接：先让浏览器能用

下面是首次安装的操作。已经在用 FlClash 的人先记录原状态，不为跟教程重启或切换正在使用的住宅连接。

4.1 选择“规则”模式

打开 仪表盘，找到 出站模式，选择 规则。卡片的位置可以自定义，按名称找，不按截图坐标找。

三种模式的区别是：

  • 规则：按网站和地址的规则选择连接。本教程后面的 AI/大陆分流用它。
  • 全局：普通分流规则不再负责逐网站选路，主要使用全局组选择。适合临时检查，不作为本文的日常分流方式。
  • 直连：使用设备所在网络直接连接，不能实现本文的海外 AI 固定代理出口。

4.2 Mac、Windows、Linux：开启系统代理

先点击开始连接的 ▶ 播放图标；运行后变成暂停图标，部分布局还显示运行时长。然后在仪表盘找到 系统代理，打开开关。它把本机代理入口写到系统设置里，浏览器等遵循这个设置的应用才会使用它。官方运行控件

虚拟网卡/TUN 暂时不作为首次联网的前置步骤。 系统代理不覆盖所有开发工具、游戏或 UDP 流量；后面确有需要时再按应用检查，不能把“浏览器已能用”当成“所有软件都被接管”。

4.3 Android：接受 VPN 连接授权

手机用 FlClash 的开始连接控件，按 Android 弹窗确认 VPN 连接。不要在手机上寻找桌面的“系统代理”卡片。VPN 接管范围、排除应用和其他 VPN 是否冲突，要在手机上单独确认。Android 官方机制

4.4 选择一个普通出口

  1. 进入 代理。
  2. 找到配置中的普通网站入口组，常见名称有“节点列表”“代理”“Proxy”；名字由订阅作者决定。
  3. 点击这个组的页签或入口，查看它的成员。
  4. 如果有 自动选择/URLTest，先选它；如果没有，先选一个服务商提供的节点。点击成员是在设置当前组的选择。
  5. 如需测速，用页面的 延迟测试 入口；0.8.99 可能显示为 ⚡ 闪电图标，按提示名找。数字越小，只表示这次测试目标响应更快；Timeout 表示这次探测没在期限内成功。
  6. 在浏览器打开一个你本来就能打开的大陆网站，再打开一个无需登录的海外公共网页，例如 GitHub。

完成标志：客户端正在运行，浏览器页面能加载，并且新请求在客户端的“请求/连接”页出现。若海外页面失败，先检查活动配置、系统代理、模式和选中的成员；不要同时改十个开关。

5. 为什么代理页面选了日本，Claude 还能走美国

顺序是：某个网站发起连接 → 第一条匹配的规则指定目标 → 若目标是代理组，该组再按当前选择决定节点。

例如，配置里有两个独立的组：“海外AI”和“普通出口”。Claude 的规则指向“海外AI”，普通网页的规则指向“普通出口”。你在普通出口组中选日本节点，只改变使用普通出口组的连接；它不会自动改掉海外AI组的美国住宅选择。

在代理页面顶部看到多个页签，通常是在看不同组，不是同一开关的几种外观。先点组名，再看它目前选了谁。主组也可能选择“自动选择”这个子组，子组再决定真正的节点。

验证时打开一个新请求，到“请求/连接”页看它的域名、命中规则和连接链。已有视频、下载、AI 流式回答可能还在原连接上，不要为了看结果点击“关闭全部连接”。

6. 再添加 AI 的固定出口需求

先写清你希望哪些服务怎么走，再改配置。本仓最新案例的政策是：

流量 希望使用的连接
中国 AI，例如 DeepSeek、Kimi DIRECT
中国大陆普通网站，例如抖音 DIRECT
指定的海外 AI，例如 Claude 已验证的固定住宅代理，日常不额外串香港上游
其他海外网站 原来的普通分流和自动选择组

“住宅直连”仍然经过住宅代理，只是不再增加另一层上游；它和 Clash 的 DIRECT 含义不同。

若你还没有住宅代理，先完成普通联网即可。若确实需要固定住宅出口，再向已有供应商取得对应代理信息，在本机确认协议、授权方式和连通性。不能把任意机场节点改名为“住宅”就当作完成。也不能把 HTTP 地址直接填进 VLESS 节点里，协议必须一致。

已有住宅节点时，在代理页记下它的完整名称，包括空格和符号。后面的 YAML 或 Skill 用这个名字引用它；密码和真实服务地址不用发给智能体。

中国 AI 按你批准的供应商政策分类，不能只看域名是不是 .cn 或服务器在哪个国家。规则清单也会更新；实际常用的 AI 网站、API 和开发工具应逐一确认。

7. YAML 是什么，怎么开始写

YAML 是用普通文字保存设置的文件格式。你不用从空白手抄所有机场节点：第 3 节已经导入一份完整配置，现在学习在它上面做局部修改。

7.1 先学四个写法

proxy-groups:
  - name: "海外AI"
    type: select
    proxies:
      - "我的住宅节点"

逐行读：

  • proxy-groups:：接下来是一组代理组的定义。
  • - name: "海外AI"：列表里的一个组，名字是“海外AI”。行首的 - 表示列表项目。
  • type: select：这个组由你手动选择成员。
  • proxies: 后面的缩进列表：这个组可以选哪些已存在的节点或组。
  • "我的住宅节点"：这里必须换成代理页的实际完整名称。引号能把空格、中文和符号放在同一个名字中。

同一级用相同数量的空格缩进，推荐按例子每层两格；不用 Tab。英文冒号 : 后有一个空格。# 后的文字是注释。不能把中文冒号 ： 或弯引号当成 YAML 标点。

7.2 认识文件里的三个部分

部分 你在这里改什么
proxies: 单个节点的连接参数；通常由供应商提供，初学者保留原内容
proxy-groups: 给节点分组，以及设置手动或自动选择关系
rules: 让网站使用 DIRECT、某个节点或某个组

完整订阅还可能有 proxy-providers、rule-providers、DNS 等。先不删除它们。本仓通用模板带占位符，供准备计划，不是让你直接替换完整订阅。

已有机场节点时保留供应商提供的节点内容。若你另外拿到了 HTTP 代理，节点的写法可以这样认识：

proxies:
  - name: "我的住宅节点"
    type: http
    server: "<供应商提供的服务器地址>"
    port: <供应商提供的端口数字>
    username: "<供应商提供的用户名>"
    password: "<供应商提供的密码>"

这只是待填写的节点片段。服务器地址、端口和认证来自供应商后台，只在本机私人编辑器中填写；替换所有 <...>，端口填纯数字。没有用户名密码、使用来源 IP 授权的服务，应按供应商说明省略那两行；密码含引号或反斜杠时让可信本地工具正确编码，不上传密码。HTTPS、SOCKS5、VLESS 等连接方式的参数不同，不能把这份 HTTP 示例硬套过去。HTTP 字段说明

实际添加时把这一个 - name 节点追加到现有 proxies: 列表，不重复粘贴顶层标题。是否真是住宅、是否能固定出口，要另行验证；这个 name 只是你的命名。

7.3 做一处看得懂的修改

假设你现有配置已经有“普通出口”和“自动选择”，已有一个名叫“我的住宅节点”的可用节点。以下两个例子只展示要改的部分；它们都不是完整节点配置。

修改前：

proxy-groups:
  - name: "普通出口"
    type: select
    proxies:
      - "自动选择"

rules:
  - "MATCH,普通出口"

修改后：

proxy-groups:
  - name: "普通出口"
    type: select
    proxies:
      - "自动选择"
  - name: "海外AI"
    type: select
    proxies:
      - "我的住宅节点"

rules:
  # 实际合并时，原有 REJECT、安全、内网/VPN 优先规则留在前面。
  - "DOMAIN-SUFFIX,deepseek.com,DIRECT"
  - "DOMAIN-SUFFIX,kimi.com,DIRECT"
  - "DOMAIN-SUFFIX,kimi.ai,DIRECT"
  - "DOMAIN-SUFFIX,moonshot.ai,DIRECT"
  - "DOMAIN-SUFFIX,anthropic.com,海外AI"
  - "DOMAIN-SUFFIX,claude.ai,海外AI"
  - "DOMAIN-SUFFIX,douyin.com,DIRECT"
  # 原有大陆直连及其他规则保留在这里，顺序经过核对。
  - "MATCH,普通出口"

一条规则的三个逗号分隔字段分别是“匹配方式、要匹配的内容、连接目标”。例如 DOMAIN-SUFFIX,claude.ai,海外AI 包含 claude.ai 及它的子域名；MATCH 表示前面都没匹配到时使用的最后一条规则，留在末尾。

中国 AI 规则在广泛 AI 规则前；海外 AI 规则在广泛大陆规则前。这张示例只含少量域名，不覆盖所有中国网站、AI 或登录依赖。实际合并必须保留原大陆分类，按你用的服务补齐域名。不要删除原 rules 后只贴这几行。

你实际只做两件事：在现有 proxy-groups: 列表中增加一个组；在现有 rules: 的适当位置增加规则。不要在文件末尾再粘贴第二个同名顶层 rules: 或 proxy-groups:。如果已有“海外AI”组，先编辑已有定义，不创建重名组。

所有示例名称都要对应你的实际配置。如果没有自动选择组，保留原普通出口的完整成员；如果住宅节点不在原配置中，先完成节点的私人导入和测试，不能只写一个名称让节点凭空出现。

7.4 打开编辑器、保存和加载

FlClash 的入口是：配置卡片的菜单 → 编辑 → “配置”这一行的 ⋮ → 编辑。先在内层编辑器保存，再回外层编辑页保存；0.8.99 的外层保存是 ✓ 勾号，0.8.98 是保存按钮。官方编辑实现

第一次改文件，按这个顺序：

  1. 先备份：配置 → 当前卡片的 ⋮ → 更多 → 导出文件。把完整配置保存在本机私人位置，不上传。全应用备份的入口是工具 → 备份与恢复 → 本地 → 备份。
  2. 用 FlClash 编辑器，或普通文本编辑器编辑副本。Mac 文本编辑要使用“纯文本”；Windows 记事本保存为 UTF-8。文件名以 .yaml 结束，不是 .yaml.txt。
  3. 只合并上一节说明的组和规则，保留节点认证、订阅、DNS、其他组和最后的 MATCH。
  4. 让客户端或可信本地工具检查缩进、重名、成员引用和当前内核兼容性。出现错误先修正，不继续加载。
  5. 安排可以接受配置重新加载的时间，再保存并应用到当前配置。不要承诺现有连接完全不受影响；正在开会、下载或使用住宅连接时，可以先只保存私人副本，不加载。
  6. 到代理页选 海外AI → 实际住宅节点；到普通出口组确认仍是你原来的选择。
  7. 用新请求查看 Claude、一个中国 AI、抖音及普通海外网页的命中结果。

如果改的是 URL 订阅，自动更新可能覆盖直接编辑。FlClash 会提示是否关闭自动更新；不能一边关掉又说订阅照常更新。需要长期保留补丁和订阅更新时，使用当前版本支持的局部覆写/合并方式，让 Skill 先给具体方案。

完成标志：客户端没有配置错误，新请求走到了希望的目标，原订阅和普通网站仍能用。如果只有文件保存成功、客户端没加载，还不算修改生效。

8. Skill 安装在哪，怎么安装

Skill 是一套给智能体读取的操作说明，附带参考文件和可选助手。它安装在 Codex、Claude Code 等智能体工具里；FlClash 仍负责网络连接。Skill 不提供节点、不自动登录账号，也不代替你的系统授权。

本篇优先教自然语言交互，不要求你先运行 Python 助手。原助手仅支持文档规定的 Mihomo 高级子集，不能自动完成这里的中国 AI 优先和普通自动组选路。

8.1 Codex：在对话里安装

已有本地 Codex 时，新建或打开一个本地对话，发送：

$skill-installer 请从 https://github.com/iPythoning/goglobal-infra 安装 skills/flclash-ai-privacy。只安装 Skill，不修改我的网络。如果同名 Skill 已存在，先告诉我来源和版本，不直接覆盖。安装完成后告诉我实际安装位置，以及如何在下一轮调用它。

等它报告完成，再在下一条消息里输入 $flclash-ai-privacy。若选择列表没有出现，先开新对话重新查看，必要时按工具说明重启 Codex；这不要求你重启 FlClash。

当前 Codex 文档推荐的用户目录为 ~/.agents/skills，旧安装器也可能使用自己的技能目录，以安装器报告为准，不在几个目录各装一份。Codex 官方 Skill 说明

8.2 Claude Code 或手工安装

  1. 打开本仓发布下载页，下载 goglobal-infra-版本号.zip，不要只下载单个 SKILL.md。
  2. 解压后找到 skills/flclash-ai-privacy 文件夹。文件夹里面应有 SKILL.md、references、templates、scripts 等，整个文件夹一起保留。
  3. Claude Code 的个人技能放在 ~/.claude/skills/flclash-ai-privacy/。在 Claude Code 对话中发送下面的安装消息，并指定刚解压的公开 Skill 文件夹，让它创建缺少的目录并复制。Mac 隐藏目录以点开头，初学者不用在 Finder 里猜怎么创建。Windows 原生安装与 WSL 使用不同用户目录，让正在运行的 Claude Code 确认自己的目录。
  4. 在 Claude Code 新会话输入 /flclash-ai-privacy，确认它识别到该技能。Claude Code 官方安装位置与调用说明

给 Claude Code 的安装消息：

我已解压刚下载的公开 Skill。请把我指定的 flclash-ai-privacy 文件夹完整安装到当前用户的个人技能目录，缺少目录就创建。如果同名已存在，先报告，不直接覆盖。只安装这些公开文件，不读取或修改网络配置。安装后告诉我如何调用。

如果它需要源文件夹位置，Mac 在 Finder 选中该文件夹后按 Option + Command + C 复制路径；Windows 可用右键“复制为路径”，再把这份公开 Skill 的位置提供给它。路径不包含代理密码或订阅，但也不用发到公开评论区。工具没有本地文件权限时，它应交付手工复制步骤，不能报告已经安装。

普通网页聊天或云会话不一定能看见你电脑上的客户端。只会聊天、没有本地文件和应用操作权限的工具，可以读文档并给手工步骤，不能声称替你配置了本机。

完成标志：工具能说出 Skill 名称和已读取的内容，不只是说“文件下载成功”。安装名保留 flclash-ai-privacy，显示标题是 Clash 家族通用版。

9. 安装后，每一轮怎么和智能体说

按下面顺序发消息。Codex 用 $flclash-ai-privacy，Claude Code 用 /flclash-ai-privacy；选择一种即可。不要一次发送所有轮次，让它先给当前步骤的结果。

第 1 轮：确认它看得到什么

$flclash-ai-privacy 我是第一次用 Clash。请先确认你已经读取这份 Skill，并告诉我你能否检查我这台电脑上的客户端、配置和新连接。如果不能操作，请给我需要自己点击的步骤，不要假装已经完成。

你要看到的结果：它说明工具能力和当前读到的客户端。如果它连使用哪台设备都不知道，你补充“当前这台 Mac/Windows 电脑”或“另一个 Android 手机”，不要发密码。

第 2 轮：只检查，不改动

先只读检查我的活动配置、客户端和内核版本、出站模式、系统代理/TUN，以及各个组当前选了谁。不要切换住宅节点、重启核心、关闭连接或修改 DNS。不要读取回显凭据、私人订阅链接或完整原始配置。请用我能理解的话说清哪些已确认、哪些没测。

你要看到的结果：客户端/内核和配置名称、模式、组的选择、能验证的范围。它不应把延迟卡的数字当成所有应用稳定的证明。

第 3 轮：说明你要的分流，拿到具体计划

我的需求是：中国 AI 和大陆普通网站 DIRECT；我实际使用的海外 AI 走现有已验证固定住宅节点；其他流量按原分流使用合适的普通路径。保留订阅更新和原自动组成员。请先生成私人本地副本，逐项说明会增加/修改哪条规则、哪个组，以及如何恢复。先不要加载。

你再补充实际应用名，例如 Claude 网页、Claude API、某个开发工具、DeepSeek、抖音。缺少合格住宅节点时，让它说明缺项，不能自动拿“最快机场节点”代替固定出口。节点名称可以说，认证留在本地。

你要看到的结果：具体改动、当前内核能否支持、加载是否可能重连、回滚方式。只有一段“建议用住宅 IP”的文字，还不是可以执行的计划。

第 4 轮：决定现在是否加载

如果计划符合你的需求，且可以接受短暂重连，发送：

同意应用刚才这份已经说明的局部补丁。保持 FlClash 开启和当前住宅选择；不停止或重启核心，不关闭全部连接。我接受配置加载可能导致的短暂重连。先完成本地校验，再按这个版本的实际加载方式应用，并验证新请求。

如果你此时不能接受重连，改为发送：

现在不加载。先保留已经检查过的私人副本和恢复步骤，告诉我以后可以重新加载时从哪里继续。

已经授权同一份修改后，不需要为了每个普通检查重新确认。若实际客户端必须重启才能生效，就不能把“已写文件”说成“已上线”；它应解释这个限制。

第 5 轮：核对结果

请用新连接分别验证 Claude/我的海外 AI、中国 AI、douyin.com、普通海外网站的规则和路径。保留正在进行的旧连接。把已生效的配置、实际请求结果、失败以及未测项目分别说清；不要把通用查 IP 页、HTTP 401/404 或第三方检测分数当作全部验证通过。

你要看到的结果：这些应用实际命中了什么规则和组；有条件时再独立检查 DNS、浏览器 UDP/WebRTC 与 IPv6。文件解析成功、普通网页打开、账号可以使用是不同结果。

以后突然 Timeout，或要增加一个新应用

排障消息可以这样发：

我在使用某应用时突然 Timeout，大概发生在这个时间。请先检查当前路径、本地网络、DNS 和实际请求的失败阶段。不要切换我的住宅出口、批量测速所有节点或重启网络。给我证据和一个可以分步验证的修改建议。

增加应用可以这样发：

我新增了这个 AI 应用/域名。请先检查现有规则是否已经覆盖；按之前批准的中国 AI DIRECT、海外 AI 固定出口政策生成局部补充，保留其他分流和订阅。

10. 小白常见卡点

问题 先检查这一步
软件装好了，没有节点 回第 3 节；客户端不自带可用订阅
代理页有节点，网页仍打不开 查活动配置、运行状态、规则模式、系统代理或 Android VPN 授权、组选择
浏览器能用，开发工具不行 该工具可能不遵循系统代理；让 Skill 查它自己的代理设置，必要时另评估 TUN
延迟低但用起来卡 延迟卡只测一个探测目标；检查实际业务的新请求和失败阶段
所有节点突然 Timeout 检测目标、DNS、宽带或上游都可能影响；不能仅凭卡片判定所有机场线路坏了
中国 AI 走了海外节点 查中国 AI 规则是否在广泛 AI 规则前，以及该 API 的实际域名
YAML 保存报错 先查空格缩进、英文标点、节点全名、重复组或重复顶层字段
更新订阅后改动没了 直接编辑的订阅被更新覆盖；准备持久化覆写/合并方案
Skill 说已经配置，实际没变化 要它核对活动配置、最终生效设置和新连接，不只看副本

Claude 的可用地区和账号资格以Anthropic 官方政策为准；固定美国 IP、住宅标签和第三方“防封分数”都不能保证账号安全。匿名 API 返回 401/404 可能只说明 HTTP 请求已到达服务，不代表认证成功或模型可用。

11. 完成入门后再学什么

你已完成入门的标志是：知道客户端和节点分别由谁提供；能导入并选择配置；能在规则模式下完成首次联网；能解释规则与代理组的关系；能在私人副本里做一处 YAML 修改；能分轮让 Skill 检查、准备、应用和验证。

随后按实际需要阅读进阶排障教程：它保留原案例的 DNS、WebRTC、IPv6、香港上游和历史检测材料，属于 Mihomo 版本相关操作。链式中转和 TUN 都不能保证公网零抖动，不作为每个人都必须开启的“优化开关”。最新日常政策另见脱敏案例。
